# めちゃくちゃ頭の悪いブロック崩し
タイトル通りめちゃくちゃ頭の悪いブロック崩しです。

## 通常のブロック崩しと違うところ
* クリックすれば好きなだけボールを出せる安心仕様、ボールを投げていればそのうちいつかは当たる。
* ボールに対してブロックが逃げちゃう(ブロックもビックリするので)
* M キーを押すとめっちゃ凄いレーザービームが発射できる。

## 操作
- マウス移動: パドル移動
- WASD or ↑←↓→: パドル移動
- クリック: ボール発射
- R: リスタート
- M: めっちゃ凄いレーザービームの発射
