# めちゃくちゃ頭の悪いブロック崩し
タイトル通りめちゃくちゃ頭の悪いブロック崩しです。

## 通常のブロック崩しと違うところ
* クリックすれば好きなだけボールを出せる安心仕様、ボールを投げていればそのうちいつかは当たる(親切)
* ボールに対してブロックが逃げちゃう(ブロックもビックリするので)

## ゲームの URL
https://ant2357.github.io/baka-breakout/

## ローカルでの起動
```bash
npm install
npm run dev
```

## 操作

- マウス移動: パドル移動
- クリック: ボール発射
- R / ゲームクリア後のクリック: リスタート
